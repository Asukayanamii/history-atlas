## 1. 通用约定

| 项 | 约定 |
| --- | --- |
| 协议 | HTTPS，仅 `application/json; charset=utf-8`（文件上传用 `multipart/form-data`） |
| Base URL | `https://api.history-atlas.cn/api/v1`（开发环境 `http://127.0.0.1:8000/api/v1`） |
| 字段命名 | camelCase |
| ID | 字符串前缀 + ULID，如 `evt_01J9Z3K4T7`、`res_...`、`qst_...` |
| 时间 | ISO 8601 带时区，如 `2026-11-08T18:00:00+08:00` |
| 分页 | `page`（从 1 开始，默认 1）、`pageSize`（默认 20，最大 50） |
| 排序 | `sort=field:asc|desc`，未指定用接口默认值 |
| 幂等 | 提交答题按 `(setId, questionId)` 幂等；重复提交覆盖为最后一次 |
| 限流 | 按接口分级，超限返回 `429` + `Retry-After` 头 |
| 追踪 | 响应带 `requestId`，日志可按其检索 |

### 1.1 统一响应

成功：

```json
{
  "code": 0,
  "message": "ok",
  "data": { },
  "requestId": "req_01J9Z4A0K1"
}
```

失败：

```json
{
  "code": 40101,
  "message": "登录已过期，请重新登录",
  "data": null,
  "requestId": "req_01J9Z4A0K1"
}
```

分页数据放在 `data` 内：

```json
{ "items": [], "page": 1, "pageSize": 20, "total": 137 }
```

### 1.2 鉴权

| 项 | 约定 |
| --- | --- |
| 方式 | `Authorization: Bearer <accessToken>` |
| accessToken | JWT，有效期 2 小时，载荷含 `sub`（userId）、`role`、`exp` |
| refreshToken | 不透明串，有效期 30 天，仅用于换发，服务端可吊销 |
| 角色 | `guest` / `student` / `teacher` / `admin` |
| 免鉴权 | 沙盘、教材、公开资源、搜索、题目详情（答案字段按角色裁剪） |

### 1.3 错误码

| code | HTTP | 含义 |
| --- | --- | --- |
| 0 | 200/201 | 成功 |
| 40001 | 400 | 参数校验失败（`data.fieldErrors` 给出字段与原因） |
| 40101 | 401 | 未登录或 accessToken 失效 |
| 40102 | 401 | refreshToken 失效，需重新登录 |
| 40301 | 403 | 无权限（如未认证教师上传资源） |
| 40401 | 404 | 资源不存在或已下架 |
| 40901 | 409 | 冲突（手机号重复、状态不允许该操作） |
| 42901 | 429 | 超出频率限制 |
| 50001 | 500 | 服务内部错误 |
| 50002 | 502 | 上游 AI 服务不可用 |
| 50003 | 504 | 检索/生成超时 |

业务兜底说明：问答未命中教材时**不是错误**，返回 `200` 且 `data.found=false`。

### 1.4 频率限制

| 接口 | 限制 |
| --- | --- |
| `POST /auth/sms-code` | 同号 60s/次，10 次/日；同 IP 30 次/小时 |
| `POST /chat/ask` | 20 次/分钟/用户，200 次/日/用户 |
| `POST /questions/generate` | 5 次/分钟/教师，50 次/日/教师 |
| 其他写接口 | 60 次/分钟/用户 |

## 4. 认证 Auth

### 4.1 发送验证码

| 项 | 值 |
| --- | --- |
| 方法 | `POST /auth/sms-code` |
| 鉴权 | 否 |
| 限流 | 同号 60s/次 |

请求：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| phone | string | 是 | 11 位手机号 |
| scene | string | 是 | login / bind |

响应 `data`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| expiresIn | int | 有效期（秒），默认 300 |
| cooldown | int | 下次可发送的等待秒数，默认 60 |

错误：`42901`（频率超限）、`40001`（手机号格式错误）

### 4.2 登录 / 注册

| 项 | 值 |
| --- | --- |
| 方法 | `POST /auth/login` |
| 鉴权 | 否 |

请求：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| phone | string | 是 | 手机号 |
| code | string | 是 | 6 位验证码 |
| deviceId | string | 否 | 设备标识，用于风控与登录设备记录 |

响应 `data`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| accessToken | string | JWT，2 小时 |
| refreshToken | string | 30 天 |
| expiresIn | int | accessToken 有效期（秒） |
| isNewUser | bool | 是否新注册 |
| user | User | 用户信息 |

错误：`40001`（验证码错误/过期）、`42901`

示例：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "accessToken": "eyJhbGciOi...",
    "refreshToken": "rt_01J9Z...",
    "expiresIn": 7200,
    "isNewUser": true,
    "user": { "id": "usr_01J9Z", "nickname": "学生_3821", "role": "student", "teacherStatus": "none" }
  },
  "requestId": "req_01J9Z4A0K1"
}
```

### 4.3 续期

| 项 | 值 |
| --- | --- |
| 方法 | `POST /auth/refresh` |
| 鉴权 | 否（携带 refreshToken） |

请求：`{ "refreshToken": "rt_..." }`
响应：同 4.2 的 `accessToken` / `refreshToken` / `expiresIn`
错误：`40102`

### 4.4 退出登录

| 项 | 值 |
| --- | --- |
| 方法 | `POST /auth/logout` |
| 鉴权 | 是 |

行为：吊销当前 refreshToken。响应 `data: null`。

### 4.5 我的信息

| 项 | 值 |
| --- | --- |
| 方法 | `GET /auth/me` |
| 鉴权 | 是 |

响应 `data`：User 对象（phone 脱敏）。

### 4.6 修改资料

| 项 | 值 |
| --- | --- |
| 方法 | `PATCH /auth/me` |
| 鉴权 | 是 |

请求（至少一项）：`nickname`（2–20 字）、`grade`、`avatarUrl`

响应 `data`：更新后的 User。

### 4.7 教师认证

| 项 | 值 |
| --- | --- |
| 方法 | `POST /auth/teacher-apply` |
| 鉴权 | 是 |

请求：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| realName | string | 是 | 真实姓名 |
| school | string | 是 | 学校 |
| subject | string | 是 | 学科，默认「历史」 |
| evidenceUrls | string[] | 是 | 证明材料（工牌/在职证明），1–3 张 |

响应 `data`：`{ "teacherStatus": "pending" }`
错误：`40901`（已提交过且审核中）

查询状态：`GET /auth/teacher-apply` → `{ "teacherStatus": "pending", "rejectReason": "" }`

## 6. 资源 Resources

### 6.1 资源列表

| 项 | 值 |
| --- | --- |
| 方法 | `GET /resources` |
| 鉴权 | 否（仅返回 published） |

查询参数：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| q | string | 标题/正文关键词 |
| type | string | 资源类型，可重复传 |
| eventId | string | 关联事件 |
| knowledgePointId | string | 关联知识点 |
| themeId | string | 时期 |
| sort | string | `createdAt:desc`（默认）/ `hot:desc` |
| page / pageSize | int | 分页 |

响应 `data`：分页，`items` 为资源摘要对象（id, type, title, summary, source, owner, createdAt）。

### 6.2 资源详情

| 项 | 值 |
| --- | --- |
| 方法 | `GET /resources/{id}` |
| 鉴权 | 否 |

响应 `data`：完整 Resource；额外含 `related`（同事件/同知识点的资源各 5 条）与 `citation`（规范引用文本）。

### 6.3 创建资源

| 项 | 值 |
| --- | --- |
| 方法 | `POST /resources` |
| 鉴权 | 是（teacher，且 teacherStatus=approved） |

请求：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| type | string | 是 | 六类之一 |
| title | string | 是 | ≤ 80 字 |
| summary | string | 否 | ≤ 200 字 |
| body | string | 条件 | 文本类必填 |
| fileUrl | string | 条件 | 文件类必填（先调 `POST /files`） |
| eventIds | string[] | 否 | ≤ 5 |
| knowledgePointIds | string[] | 是 | 1–5 |
| source | string | 是 | 出处 |
| license | string | 是 | 许可 |

响应 `data`：Resource（status = `draft`）

错误：`40301`（未认证教师）、`40001`

### 6.4 修改资源

| 项 | 值 |
| --- | --- |
| 方法 | `PATCH /resources/{id}` |
| 鉴权 | 是（作者或 admin） |

可改字段：同创建；`published` 状态的修改需重新审核（`status` 自动回到 `pending`）。

### 6.5 提交审核

| 项 | 值 |
| --- | --- |
| 方法 | `POST /resources/{id}/submit` |
| 鉴权 | 是（作者） |

行为：校验必填元数据 → `draft/rejected` → `pending`。
响应 `data`：`{ "status": "pending" }`
错误：`40901`（状态不允许）、`40001`（缺必填项，`fieldErrors` 指明）

### 6.6 删除资源

| 项 | 值 |
| --- | --- |
| 方法 | `DELETE /resources/{id}` |
| 鉴权 | 是（作者或 admin） |

限制：`published` 资源不能删除，只能由 admin 下架。响应 `204`。

### 6.7 我的资源

| 项 | 值 |
| --- | --- |
| 方法 | `GET /resources/mine` |
| 鉴权 | 是 |

查询：`status`、`type`、分页。响应含 `rejectReason`。

### 6.8 资源类型字典

| 项 | 值 |
| --- | --- |
| 方法 | `GET /resources/types` |
| 鉴权 | 否 |

响应 `data`：`[{ "value": "textbook", "label": "教材片段" }, ...]`

## 9. 问答 Chat

### 9.1 提问

| 项 | 值 |
| --- | --- |
| 方法 | `POST /chat/ask` |
| 鉴权 | 是 |
| 限流 | 20 次/分钟/用户 |

请求：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| question | string | 是 | 1–500 字 |
| sessionId | string | 否 | 不传则新建会话 |
| context | object | 否 | `{ eventId?, chunkId?, knowledgePointId? }`，用于事件页内追问 |
| stream | bool | 否 | 默认 false；true 时按 SSE 逐字返回 |

响应 `data`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| messageId | string | 消息 ID |
| sessionId | string | 会话 ID |
| answer | string | 回答正文（Markdown） |
| found | bool | 是否在教材中检索到相关内容 |

## 10. 题目 Questions

### 10.1 题目列表

| 鉴权 | 否（答案字段按角色裁剪） |

响应 items 字段：`{id, qtype, stem, options, difficulty, knowledgePointIds, sourceType, sourceMeta, reviewStatus}`；学生端 `answer`、`analysis` 仅在提交后返回。

### 10.2 题目详情

`GET /questions/{id}` → `{ question, answer?, analysis?, citations }`
`answer/analysis` 仅对已作答用户、教师、管理员返回。

### 10.3 录入原题

| 项 | 值 |
| --- | --- |
| 方法 | `POST /questions` |
| 鉴权 | 是（teacher approved / admin） |

请求：`qtype`、`stem`、`options`、`answer`、`analysis`、`difficulty`、`knowledgePointIds`、`sourceMeta{exam,year}`、`textbookRef`
响应：Question（`sourceType=original`，`reviewStatus=pending`）

### 10.4 AI 生成题目

| 项 | 值 |
| --- | --- |
| 方法 | `POST /questions/generate` |
| 鉴权 | 是（teacher / admin） |
| 限流 | 5 次/分钟 |

请求：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| knowledgePointIds | string[] | 是 | 1–3 个 |
| count | int | 是 | 1–10 |
| difficulty | string | 否 | easy/medium/hard，默认 medium |
| qtype | string | 否 | single（默认）/ multiple |

## 14. 状态机

### 14.1 资源状态

```text
draft ──submit──▶ pending ──approve──▶ published
  ▲                  │                    │
  │                  └──reject──▶ rejected │
  └──────────── edit ────────────────────┘（published 编辑后回到 pending）
published ──admin offline──▶ rejected
```

### 14.2 题目审核状态

```text
pending ──approve──▶ approved（进入公共题库）
   └──────reject────▶ rejected（仅个人/教师可见）
```

### 14.3 教师认证

```text
none ──apply──▶ pending ──approve──▶ approved
                  └──reject──▶ rejected ──re-apply──▶ pending
```

## 15. 静态数据迁移说明

一期前端沙盘数据位于 `frontend/src/data/`（`theme.*.js`、`themes.index.js`、`assets.js`、`dem/regions.js`）。接入后端后：

| 前端现状 | 后端接口 | 处理 |
| --- | --- | --- |
| `themes.index.js` 的时期顺序与项目信息 | `GET /atlas/themes` | 前端保留兜底默认值，接口成功后覆盖 |
| `theme.*.js` 的 `events[]` | `GET /atlas/themes/{id}` | 字段名保持 `id/title/date/year/location/summary/knowledgePointIds` |
| 事件插画与封面清单 `assets.js` | `GET /atlas/events/{id}` 内的 `coverUrl` | 资源地址改由 CDN 返回，前端 `HS.assets` 增加远程加载分支 |
| `dem/regions.js` 高程 | 无 | 保留为静态构建产物，不进接口 |
| 事件级场景（war/court/VR） | 无 | 产品范围外，随前端精简移除 |
