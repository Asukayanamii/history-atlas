## 1. 背景与问题

高中历史学习中，学生面对三类高频痛点：

1. **知识是碎的**：教材按单元—课—子目组织，学生记住的是孤立结论，缺乏时空框架，容易「背了不会用」。
2. **答疑不可信**：通用大模型会一本正经地编造史实与年份，学生无法判断对错，也不敢用来复习。
3. **练习与资源割裂**：题目、教材、史料、地图分散在不同地方，做完题不知道回哪一段教材补，教材看完不知道练哪些题。

市面上要么是纯题库，要么是纯 AI 陪聊，要么是给教师用的教学平台，**没有一个把「可信资源 + 时空索引 + 可溯源问答」放在一起、面向大众学生自学的产品**。

## 2. 产品定位

> **面向大众的历史资源聚合网站**：以三维沙盘为首页索引，把历史事件、知识点与资源（教材片段、史料、图片、试题）连成一张时空可导航的网，再用可溯源的智能体完成答疑与练习。

一句话区分：

| 不是 | 是 |
| --- | --- |
| 班级管理平台（作业、考勤、家长端） | 学生自主学习 + 大众可访问的资源站 |
| 3D 历史游戏 / 场景演示产品 | 以**索引**为核心的空间化知识导航 |
| 通用 AI 聊天机器人 | 强约束在教材与自有库上的问答，答不出就承认 |

## 3. 目标用户与角色

| 角色 | 说明 | 主要诉求 |
| --- | --- | --- |
| 学生（主要用户） | 高中生为主，手机 H5 访问 | 快速建立时空框架；问得准；练得对；错题能回到教材 |
| 教师 / 资源贡献者 | 历史教师、教研人员、内容爱好者 | 上传并维护资源、补题目、参与审核 |
| 访客 | 未登录用户 | 浏览沙盘与公开资源，被引导注册 |
| 管理员 | 内部运营 | 资源审核、上下架、用户与内容治理 |

**一期不做**：班级、作业、考勤、家长端、学校 SSO、多租户。

## 4. 目标与非目标

### 4.1 一期目标（可验收）

| 编号 | 目标 | 衡量方式 |
| --- | --- | --- |
| G1 | 沙盘可作为首页完成「时期 → 事件 → 资源 / 知识点」的完整导航 | 任选一个事件，3 次点击内到达其关联的教材片段与题目 |
| G2 | 教材问答可溯源、不编造 | 抽 50 个常见问题，回答与教材一致率 ≥ 90%，无出处回答占比 = 0 |
| G3 | 练习闭环可用 | 从薄弱知识点出题 → 判题 → 解析 → 错题回跳教材，全链路 ≤ 5 步 |
| G4 | 教师能自主上传资源并进入审核 | 教师上传到资源上线的全流程无人工后台干预 |
| G5 | 学生愿意再来 | 试用学生中使用 ≥ 3 次的比例 ≥ 30% |

### 4.2 明确不做（一期）

| 项 | 原因 |
| --- | --- |
| **事件级 3D 场景演示**（war 兵棋、朝堂议政、360° 环视） | 制作成本高、复用率低；本项目只保留**总体事件索引**，不做具体事件的形象化演绎 |
| 班级 / 作业 / 考勤 / 家长端 | 产品不是班级管理平台 |
| 拍照判题 / 语音输入 | 识别质量与成本不可控，放二期 |
| AI 生成题自动上线 | 生成题必须先标识来源并过审 |
| 多教材版本、初中、选修 | 一期聚焦一本教材验证 |
| 实时多人协作 / 直播 | 与核心价值无关 |

### 4.3 二期展望（不展开）

教师端增强（题目录入效率、班级学情看板）、知识图谱（前置依赖）、拍照判题、多教材版本、AI 生成题的规模化与质量评估、开放 API 与资源共建。

## 5. 核心概念与数据模型

### 5.1 概念

| 概念 | 定义 |
| --- | --- |
| 时期 Theme | 沙盘上的一个历史时段（隋唐、五代十国、宋朝…），决定地图疆域与事件集合 |
| 事件 Event | 时期下的一个历史事件节点，含时间、地点（经纬度）、一句话概述、关联知识点与资源 |
| 知识点 KnowledgePoint | 三级标签体系：一级模块 → 二级专题 → 三级知识点，是资源、题目、学情的公共锚点 |
| 教材片段 Chunk | 教材按单元/课/子目切分后的文本单元，是 RAG 检索与出处引用的最小单位 |
| 资源 Resource | 可被学生消费的内容：教材片段、史料摘录、图片、课件、试题、外链 |
| 题目 Question | 选择题为主；来源分「原题」与「AI 生成」，AI 生成题必须带标识与审核状态 |

### 5.2 关键实体字段（概要）

```text
Theme        id, name, period, mapConfig, eventIds[]
Event        id, themeId, title, date, location{lon,lat}, summary, knowledgePointIds[], resourceIds[]
KnowledgePoint id, level(1|2|3), name, parentId, textbookRefs[], eventIds[]
Chunk        id, textbookId, unit, lesson, subsection, page, content, tags[], embedding
Resource     id, type, title, url|body, ownerId, eventIds[], knowledgePointIds[], status(draft|pending|published|rejected), license
Question     id, stem, options[], answer, analysis, difficulty, knowledgePointIds[],
             sourceType(original|ai_generated), sourceMeta, reviewStatus(pending|approved|rejected)
PracticeSet  id, studentId, mode(diagnostic|weak|kp), questionIds[], createdAt
Mistake      studentId, questionId, wrongAnswer, createdAt, reviewed
```

字段级定义以[接口文档](接口文档.md)为准。

## 6. 功能需求

编号规则：`FR-模块-序号`。每条含规则与验收标准，验收标准必须可测。

### 6.1 账号与权限（FR-ACC）

| 编号 | 需求 | 规则 | 验收 |
| --- | --- | --- | --- |
| FR-ACC-01 | 手机号验证码登录 | 同一手机号未注册则自动注册；验证码 6 位、5 分钟有效、同号 60s 内不可重发、每日上限 10 次 | 新号码登录后自动创建学生账号 |
| FR-ACC-02 | 会话凭证 | 登录返回 accessToken（2h）与 refreshToken（30d）；过期自动续期 | token 过期后无感刷新，不打断答题 |
| FR-ACC-03 | 角色 | `student`（默认）、`teacher`（需认证）、`admin`（内部） | 教师身份未认证时不能上传资源 |
| FR-ACC-04 | 个人信息 | 昵称、年级、头像；手机号仅本人可见 | 他人接口不返回手机号 |
| FR-ACC-05 | 注销与数据删除 | 支持注销账号；注销后学情与上传资源按策略处理 | 注销后可申请删除个人数据 |
| FR-ACC-06 | 访客模式 | 未登录可浏览沙盘、教材与公开资源；提问与练习需登录 | 未登录点击「提问」弹出登录 |

### 6.2 资源聚合库（FR-RES）

| 编号 | 需求 | 规则 | 验收 |
| --- | --- | --- | --- |
| FR-RES-01 | 资源类型 | 教材片段（系统导入）、史料摘录、图片、课件、试题、外链 | 六类均有独立展示形态 |
| FR-RES-02 | 资源上传 | 教师可上传：标题、类型、正文/文件、关联事件、关联知识点、出处与许可 | 上传后状态为 `pending`，不进公开列表 |
| FR-RES-03 | 元数据必填 | 标题、类型、出处、许可、至少 1 个知识点 | 缺项不允许提交审核 |
| FR-RES-04 | 审核 | 管理员审核：通过 / 驳回并填原因；教师可在「我的资源」看到状态与原因 | 驳回后修改可重新提交 |
| FR-RES-05 | 检索 | 关键词（标题/正文）、类型、事件、知识点、时期组合筛选；结果分页 | 组合条件下 1 秒内返回首屏 |
| FR-RES-06 | 详情与引用 | 资源详情展示出处、许可、贡献者、关联事件与知识点 | 一键复制规范引用格式 |
| FR-RES-07 | 下架与删除 | 管理员可下架；作者可删除自己未上线的资源 | 下架资源不再出现在任何列表与问答引用中 |
| FR-RES-08 | 版权合规 | 来源不明或授权未确认的资源不得上线 | 审核清单逐项打勾才能通过 |

### 6.3 沙盘索引（FR-ATL）——首页

> 沙盘是**索引**，不是演出。地图、时期、事件点位、路线、疆域色块保留；**事件级 3D 场景（兵棋、朝堂、全景）不纳入产品范围**。

| 编号 | 需求 | 规则 | 验收 |
| --- | --- | --- | --- |
| FR-ATL-01 | 首页即沙盘 | 默认进入最近时期；顶部可切换时期；时间轴横向排列事件 | 首屏 3 秒内可交互 |
| FR-ATL-02 | 事件点位 | 事件在地图上以编号标记呈现；点击 → 事件面板 | 点位与事件一一对应，无孤立点 |
| FR-ATL-03 | 事件面板 | 展示：标题、时间、地点、概述、关联知识点、关联资源、教材出处 | 面板内可直达资源与教材片段 |
| FR-ATL-04 | 时空建模辅助 | 时间轴与地图联动：拖动时间轴高亮对应事件与疆域变化；提供「同知识点前后事件」对比 | 任一事件可看到其在时间轴上的前后邻居 |
| FR-ATL-05 | 知识点反查 | 从知识点出发，列出相关事件、教材片段、题目 | 从知识点 3 次点击内到题目 |
| FR-ATL-06 | 跨库搜索 | 全局搜索覆盖资源、事件、知识点、题目 | 关键词命中按类型分组展示 |
| FR-ATL-07 | 移动端可用 | H5 下沙盘可缩放旋转，面板抽屉化 | 375px 宽度下无横向滚动 |
| FR-ATL-08 | 弱网降级 | 地图瓦片/模型加载失败时降级为静态底图 + 事件列表 | 断网重连后自动恢复 |

### 6.4 教材知识库（FR-KB）

| 编号 | 需求 | 规则 | 验收 |
| --- | --- | --- | --- |
| FR-KB-01 | 教材结构 | 单元 → 课 → 子目 → 段落四级；片段标注页码与知识点标签 | 目录树与纸质教材一致 |
| FR-KB-02 | 片段详情 | 展示原文、所属章节、页码、知识点、关联事件、关联题目 | 每片段至少 1 个知识点标签 |
| FR-KB-03 | 语义检索 | 供问答与检索使用；相似度阈值以下不硬答 | 检索 Top-5 相关性人工抽检合格率 ≥ 85% |
| FR-KB-04 | 内容更新 | 教材修订时支持片段级更新与重新向量化，旧引用保持可解析 | 更新后历史回答的出处仍可打开 |

### 6.5 智能问答（FR-QA）

| 编号 | 需求 | 规则 | 验收 |
| --- | --- | --- | --- |
| FR-QA-01 | 教材 RAG 问答 | 先检索 Top-K 教材片段，再让模型基于片段作答；Prompt 强约束「只能用给定材料」 | 回答内容可在引用片段中找到依据 |
| FR-QA-02 | 出处引用 | 每条回答必须附 ≥ 1 条教材出处（教材、单元、课、页码、片段 ID） | 无出处的回答视为缺陷 |
| FR-QA-03 | 兜底 | 最高相似度低于阈值（初始 0.5）时不作答，返回「教材中未找到相关内容」并建议相邻章节 | 兜底触发率可监控，误触发可抽样复盘 |
| FR-QA-04 | 上下文问答 | 支持在事件页/教材页内追问，自动带入当前事件或片段作为上下文 | 进入事件后提问，答案优先引用该事件关联片段 |
| FR-QA-05 | 会话历史 | 保存最近 30 天会话；可继续历史会话 | 刷新页面后历史可恢复 |
| FR-QA-06 | 反馈 | 每条回答可「有用/无用」，无用可选原因 | 反馈进入运营看板 |
| FR-QA-07 | 安全与边界 | 与历史学习无关的请求礼貌拒绝；不输出未经考证的年份与人物 | 越界测试集通过率 100% |
| FR-QA-08 | 响应体验 | 非流式 ≤ 6s（P95）；超时给出可重试提示 | 超时率 < 1% |

### 6.6 练习与出题（FR-EX）

| 编号 | 需求 | 规则 | 验收 |
| --- | --- | --- | --- |
| FR-EX-01 | 诊断卷 | 首次使用可做 30 题诊断，覆盖主要知识点，生成初始掌握度 | 完成后立即展示掌握度雷达/列表 |
| FR-EX-02 | 按薄弱点出题 | 从正确率最低的 3 个知识点取题，难度由易到难 | 同一知识点连续出题不重复（同批次） |
| FR-EX-03 | 指定知识点练习 | 用户自选知识点/时期组卷 | 题量可选 5/10/20 |
| FR-EX-04 | AI 生成题 | 教师或学生可请求生成题目；**生成题必须标识 `ai_generated` 并展示模型与生成时间** | 学生界面明确标注「AI 生成」 |
| FR-EX-05 | 生成题审核 | AI 生成题默认 `pending`，教师审核通过后才进入公共题库；个人练习可先用未过审题但打「未审」标记 | 未过审题不会出现在公共卷中 |
| FR-EX-06 | 判题与解析 | 客观题即时判分；解析含答案依据与教材定位 | 答错可直接跳转教材片段 |

| FR-EX-08 | 错题本 | 自动收录错题，可标记已复习；支持按知识点/时间筛选 | 错题可重做，重做正确后状态更新 |

## 7. 关键流程

### 7.1 学生：从沙盘到练习

```text
首页沙盘（选时期）
  → 点事件点位 → 事件面板（概述 / 知识点 / 资源 / 教材出处）
  → 选一条资源或教材片段阅读
  → 就当前事件提问（自动带上下文）
  → 做该知识点的题 → 答错 → 解析 + 「回到教材第 X 页」
  → 错题本 → 按薄弱点组卷复习
```

### 7.2 教师：资源上线

```text
注册 → 教师认证（管理员审核）
  → 新建资源（类型 / 正文或文件 / 出处 / 许可 / 知识点 / 事件）
  → 提交审核 → 管理员通过 / 驳回（填原因）
  → 上线，出现在沙盘事件页、搜索结果与问答引用中
```

### 7.3 AI 出题

```text
教师选择知识点 + 难度 + 题量 + 题型
  → 生成（标注 ai_generated、模型、时间）
  → 进入待审队列
  → 教师修订 / 通过 → 进入公共题库
  → 学生侧始终显示「AI 生成」标识
```

## 8. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 性能 | 首屏可交互 ≤ 3s（4G）；列表接口 P95 ≤ 500ms；问答 P95 ≤ 6s；沙盘帧率 ≥ 30fps（中端手机） |
| 可用性 | 月度可用性 ≥ 99%；问答与沙盘任一故障时，另一功能可独立使用 |
| 兼容性 | iOS Safari 15+、Android Chrome 100+、桌面 Chrome/Edge 100+；375px 起自适应 |
| 可访问性 | 关键操作可键盘完成；对比度符合 WCAG AA；沙盘提供事件列表替代视图 |
| 安全 | HTTPS；手机号脱敏；防刷（验证码频率、接口限流）；上传文件类型与大小校验 |
| 合规 | 未成年人个人信息最小化采集；AI 生成内容显著标识；资源版权与出处可追溯；按国内要求完成备案 |
| 可维护 | 前后端分离；接口版本化 `/api/v1`；内容与代码分离（数据可由教师维护） |
| 可观测 | 问答兜底率、平均时延、检索命中率、审核时效可监控 |

## 9. 验收标准（一期）

| 编号 | 验收项 | 通过标准 |
| --- | --- | --- |
| AC-01 | 沙盘导航 | 抽 5 个事件，均可 3 次点击内到达教材片段与题目 |
| AC-02 | 问答可信 | 50 题抽检，与教材一致率 ≥ 90%；无出处回答 = 0；越界请求 100% 拒绝 |
| AC-03 | 兜底 | 构造 20 个教材外问题，均返回「未找到」而非编造 |
| AC-04 | 练习闭环 | 组卷 → 答题 → 判分 → 解析 → 错题回跳教材，全程无死链 |
| AC-05 | AI 题标识 | 随机抽 20 道生成题，100% 带「AI 生成」标识与审核状态 |
| AC-06 | 教师上传 | 新教师账号从认证到资源上线全流程 ≤ 30 分钟（不含审核等待） |
| AC-07 | 移动端 | iPhone SE 尺寸下核心流程可完成，无遮挡与横向滚动 |
| AC-08 | 留存 | 试点 4 周，使用 ≥ 3 次的用户占比 ≥ 30% |

## 12. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 教材整理与题库录入是人力重活 | 进度延期 | 先做 1 本书；找历史专业同学/老师协作；提供批量导入模板 |
| 问答幻觉 | 信任崩塌 | 强约束 Prompt + 相似度兜底 + 出处强制 + 人工抽检 |
| 版权与授权 | 法律风险 | 只用公有领域/已授权资源；高考真题标注来源；审核清单强制 |
| AI 生成题质量不稳 | 家长/教师质疑 | 待审机制 + 标识 + 可驳回；公共库只收已审题 |
| 沙盘性能 | 中低端机卡顿 | 事件点用轻量标记、地图分级加载、提供列表降级视图 |
| 单一教材覆盖窄 | 用户觉得没用 | 一期明确定位为「一本书的深度体验」，二期扩版本 |
