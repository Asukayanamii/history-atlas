# History Atlas · 历史资源图谱

> 一个面向高中历史的 **资源聚合库 + 3D 动画索引 + AI 学习助手**。

项目不止是一个「答疑机器人」：底层是把教材、真题、史料等学习资源结构化聚合起来的知识库，中层是用 3D 动画把「单元 → 课 → 子目 → 知识点」的空间关系可视化出来的索引，上层才是基于 RAG 的问答、针对性出题与错题复盘。

---

## 三层形态

| 层 | 名称 | 说明 |
| --- | --- | --- |
| 资源层 | 资源聚合库 | 教材章节、高考真题、史料与知识点标签统一建模，支持检索与引用溯源 |
| 索引层 | 3D 动画索引 | 以时间轴 / 空间星图方式呈现知识结构，点击即下钻到具体知识点与资源 |
| 应用层 | AI 学习助手 | 基于教材 RAG 的问答、按薄弱点出题、错题本与学情统计 |

## 仓库结构

```
history-atlas/
├── backend/          # FastAPI 服务：用户 / 题库 / 学情 / 对话
├── frontend/         # Vue3 + Vant H5，含 3D 索引视图
├── docs/             # 产品与技术方案
└── README.md
```

## 技术选型（MVP）

- **前端**：Vue3 + Vant UI + Three.js（3D 索引）
- **后端**：Python FastAPI
- **检索**：Chroma 向量库 + bge-large-zh-v1.5 Embedding
- **存储**：PostgreSQL（题目 / 用户）、Redis（缓存 / 会话）
- **模型**：通义千问 / 文心一言 API
- **部署**：Docker Compose + 单台云服务器
